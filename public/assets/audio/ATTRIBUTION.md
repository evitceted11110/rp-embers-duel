# 音訊素材授權與署名

本版本使用**零外部音訊素材**，沒有音樂檔、音效檔或來源不明資產。

全部音訊由本專案的 `src/audio/web-audio-backend.ts` 使用瀏覽器 Web Audio API 即時程序化合成：

- oscillator 波形與掃頻
- gain envelope 與節奏 offset
- 動態音樂分層
- master compressor／limiter

因此沒有需要另行署名或追蹤授權的第三方音訊檔案。若日後加入任何外部或生成素材，必須在下表逐項登記後才能合併。
