# 雙職業全 24 卡／8 共鳴平衡基線（BL-01）

日期：2026-08-04  
執行者：Balance Engineer  
範圍：熔衛、影線獵人的六關短 Run；不含 1.0 內容與公開發佈。

## 方法與可重播性

`sim/class-expansion-balance.ts` 是專用、純資料的平衡基線；它不讀 DOM，所有亂數皆從 `@rogue-paradise/rng` 的具名 fork 派生。固定 seed `embers-class-balance-v1`，每個情境 10,000 局，共 24 個情境／240,000 局：

| 維度 | 覆蓋 |
|---|---|
| 職業 | 熔衛、影線獵人 |
| 技巧檔 | learning、competent、expert；分別拆開讀預兆、Space／E 執行、站位、共鳴意願與風險接受度 |
| 合法構築政策 | primary-focus `4/1/1`、toolbox `3/2/1`、balanced `2/2/2`、resonance-first（所有可達的 `3/2/1` 排列） |
| 每房記錄 | 通關、關數、時間、承傷、死亡原因、卡片選取／使用／成功、8 條共鳴的 attempts／resolved／rejected reason |

用法：`pnpm exec tsx sim/class-expansion-balance-report.ts`。單元測試以相同 seed 重跑完整資料結構，並斷言 24 卡、8 共鳴、三種指定投資型態均可達且沒有非法構築。

驗證：2026-08-04 已將完整 10,000 局／情境輸出連續執行兩次並以 `cmp` 比對完全相同；`pnpm verify` 通過（50 test files／391 tests，lint、雙 typecheck、production build；gzip 53,994 / 65,536 bytes）。

| 職業／技巧 | 模型通關率 | 平均完整 Run 時間 | 平均承傷 |
|---|---:|---:|---:|
| 熔衛 learning | 100.0% | 496.0 s | 51.9 |
| 熔衛 competent | 100.0% | 481.1 s | 43.9 |
| 熔衛 expert | 100.0% | 463.7 s | 36.6 |
| 影線 learning | 100.0% | 497.8 s | 53.7 |

這個結果**不是**「現版已平衡」的聲明：模型的敵方傷害／命中盒／實際冷卻尚未由 runtime trace 校正，故本輪沒有死亡樣本；同時 7.7–8.3 分鐘的模型時間低於規格的 10–12 分鐘中位目標。它是後續數值調整的零點，而不是 Gate 3 替代品。

## 卡片、共鳴與支配性

- 24 張卡皆至少可選取；各卡選取率為 **39.48%–70.34%**，使用成功率為 **63.30%–72.50%**。最低成功率的風險卡為 `shield-wedge`、`molten-lock-retreat`、`pinned-body-swap`、`reverse-mark-anchor`、`cross-line-borrow`（約 63.3%），符合它們要求站位／承諾的定位，仍高於「不可玩」警戒線。
- 8 條共鳴皆有 resolved 路徑。熔衛四條在已嘗試時 resolved **47.88%–48.18%**；影線四條為 **30.39%–30.52%**。影線的較低值主要由模型明列的主動風險拒絕（106,502 次）造成，不能和讀招或輸入失敗混算。
- 共鳴未成因可追溯：未選到前置 4,364,784、策略保留 502,312、讀招失敗 185,725、站位失敗 155,759、執行失敗 91,789、主動拒絕風險 106,502。
- 勝利構築最大占比兩職皆 **25.0%**（四種政策均衡抽樣），未見超過 35% 的單一政策／投資配置支配；此結果只說明這套政策樣本沒有收斂，**不**等同真人選擇率。

## 結論與最小調整提案

BL-01 通過「全卡／全共鳴可達、可重播、可歸因」門檻；不建議僅依此模型直接改 runtime 數字。下一個最小工作包應由 Gameplay 在 class run 的 replay/telemetry 加入逐房 `damageTaken`、房間清除 tick、E/Space 使用、共鳴 resolved/rejected 與死亡原因匯總，採本報同一批 seed 重跑。取得 runtime trace 後，再以 10–12 分鐘中位時間與各技巧檔勝率曲線校正敵群密度、關卡傷害或冷卻；目前沒有證據支持對任一卡直接 buff/nerf。

Gate 3 建議：可放入最終試玩前的自動驗收基線，但不可把本模型當作真人手感、Chromium 效能、音訊或 platform 驗收。特別觀察影線的「主動拒絕風險」是否在實機被玩家感知為可選擇，而不是線端可讀性不足。
