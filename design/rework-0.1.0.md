# 《餘燼決鬥場》Gate 3 重製規格 0.1.0
狀態：`rework_design_ready`
日期：2026-07-31
負責角色：Game Designer
適用範圍：Gate 3 Vertical Slice

## 1. 重製裁示
- 真人 Gate 3 已否決舊「160×90 巨像素黑底決鬥場」方向。
- 本規格不把舊畫面當作需要補強的基底，而是重新定義完整遊玩呈現。
- 新方向是勇者地下城系的即時動作像素 RPG。
- 「勇者地下城系」只指俯視地城、短房間探索、近戰交鋒與像素動畫等類型語彙。
- 不得複製任何特定作品的角色、敵人、地圖、介面、配色、圖示、動畫或資產輪廓。
- 本作自己的識別是「熄滅王城下方，勇者以三種餘燼印記改寫動作」。
- Vertical Slice 仍只驗證兩場遭遇戰與三枚 keystone 印記。
- 本規格不修改生命、傷害、冷卻、敵人數量、判定窗或其他 core 平衡。
## 2. 覆蓋與保留邊界
### 2.1 明確丟棄
- 丟棄 160×90 世界層與 8 倍整數放大的固定假設。
- 丟棄黑底中央一圈競技場就是全部世界的構圖。
- 丟棄以幾何色塊代替角色精靈的做法。
- 丟棄「全程式化零資產」作為產品方向的限制。
- 丟棄世界層與判定層刻意分裂成兩種視覺解析度的要求。
- 丟棄角色不能有真正走路、攻擊、受傷、死亡動畫的假設。
- 丟棄進入頁面後立即置身封閉決鬥場、沒有入口與出口的流程。
- 丟棄只靠粒子、輪廓和文字標籤補足可辨識性的策略。

### 2.2 可保留的技術資產
- `src/core/` 的固定 100Hz tick、決定性狀態與事件可保留。
- `RunPhase` 的 `encounter1 → draft → encounter2 → victory/defeat` 可保留。
- `TickInput` 的移動、攻擊、閃避、Q、E、選印記與快速重開可保留。
- `GameEvent` 可作為視覺與音效觸發的唯一戰鬥事實來源。
- 現有輸入重綁、失焦清空 held state 與平台設定儲存可保留。
- 現有音訊事件與音訊系統可保留，但其聲音素材與混音可依新場景重製。
- 現有三段連擊、兩種敵人、三枚 keystone 與兩場敵人編成可保留。
- 現有碰撞、傷害、冷卻、無敵幀、精準閃避和格擋尾段不可由視覺層改寫。

### 2.3 必須重建
- `src/render/` 的世界呈現、角色繪製、場景佈局、HUD 與特效假設必須重建。
- `src/visual/` 若綁定舊色塊或巨像素規則，視為可捨棄實作，不是相容性目標。
- 新表現層應直接消費公開 core 狀態，不得反向讓 core 依賴渲染。
- 美術可以使用原創 sprite sheet、tile sheet、逐幀特效或程式化輔助。
- 是否採用外部工具製作資產由 Visual Director 決定，但最終資產必須原創且可追溯。
## 3. Vertical Slice 體驗句
玩家從熄火地窖入口踏入短地城，在第一間戰鬥房學會近戰與閃避；清場後穿過開啟的石門，在印記祭壇選擇一種動作改寫，再於第二間戰鬥房立刻證明選擇，最後走向被火光照亮的出口。

## 4. 玩家前 10 秒
### 4.1 0.0–2.0 秒：看懂自己與目的地
- 畫面由黑淡入入口前室，不播放長片頭。
- 玩家位於畫面下方偏左，面朝右上方的亮門。
- 玩家是全畫面唯一帶暖白披風與橘紅劍刃反光的角色。
- 北側石門漏出金色火光，地面碎石與腳印形成自然導線。
- HUD 同時淡入，只顯示生命、三個行動槽與「前往深處」。
- 不用對話框阻擋輸入。

### 4.2 2.0–5.0 秒：立即獲得控制
- 玩家從第一幀可用 WASD 或方向鍵移動。
- 第一次移動時，地面顯示一次短促的四向移動提示，1.5 秒後淡出。
- 角色走路必須有上下起伏、披風擺動與腳步塵點，不能像圖示平移。
- 鏡頭以柔和 dead zone 跟隨，不因微小位移抖動。
- 靠近門時門縫火光增亮，告知這是可通行方向。

### 4.3 5.0–8.0 秒：建立攻擊手感
- 入口前放置一個可破壞的朽木樁，僅作表現教學，不計入戰鬥平衡。
- 木樁上方浮現目前綁定的攻擊鍵圖示，不寫死「左鍵」。
- 命中木樁會出現斬擊弧、木屑、1 幀亮閃與輕微 hit-stop。
- 未攻擊木樁也可直接通過，不得強迫完成教學。
- 木樁不能掉落資源、恢復生命或改變 core 數值。

### 4.4 8.0–10.0 秒：進入第一場戰鬥
- 玩家跨過門檻後，鏡頭向第一戰鬥房推進約半個畫面。
- 後方木門落下，前方焰奴從火盆旁起身，而不是憑空生成。
- 房間標題「熄火前室」在畫面上方短暫出現，0.8 秒內退場。
- 焰奴可操作前先有完整起身動畫，不在玩家失去控制時造成傷害。
- 第一個敵方預兆最早在玩家恢復完整控制後出現。

## 5. 短地城動線
### 5.1 總路徑
- 唯一路徑：入口前室 → 第一戰鬥房 → 印記祭壇 → 第二戰鬥房 → 出口長廊。
- 路徑總長以正常移動約 20–30 秒可走完，不把空走路當內容。
- 每個節點之間由可見門洞連接，讓玩家始終知道下一步往哪裡。
- 不設岔路、寶箱、商店、鑰匙、隱藏房或永久進度。
- 地圖形狀呈輕微 S 曲線，避免五個房間像簡報頁面水平排列。
- 所有探索段落都服務於戰鬥前後的節奏呼吸與世界可信度。

### 5.2 入口前室
- 尺寸約 12×8 個地磚。
- 下方是坍塌樓梯，構成玩家來處，但不可返回畫面外。
- 左牆有熄滅壁燈，右牆有仍燃燒的火盆，建立冷暖對比。
- 中央保留至少 6×4 地磚的自由移動區。
- 北東側門洞直接看得到第一戰鬥房的一小部分。

### 5.3 第一戰鬥房
- 尺寸約 18×13 個地磚，近似方形但不完全對稱。
- 遭遇內容保持焰奴 ×1。
- 入口位於西南側，出口位於東北側。
- 中央主戰區至少 10×8 地磚無硬阻擋，避免環境改變 core 接戰結果。
- 兩根斷柱位於邊緣，只做深度和遮擋，不進入主要戰鬥線。
- 一條地板裂縫從北牆延伸到房間三分之一處，形成視覺方向線。
- 清場前東北門有紅色封印，清場後封印碎裂、門扇抬起。

### 5.4 印記祭壇
- 尺寸約 14×9 個地磚，節奏比戰鬥房安靜。
- 祭壇位於中心偏北，三道地面鑲線向三個印記卡位置延伸。
- 玩家進入後，三枚印記以祭壇上方的浮石徽記出現。
- core 的 `draft` 階段在此轉譯為空間化選擇，而非切到無背景選單。
- 選擇時玩家可停在祭壇前，戰鬥房入口門已關閉且沒有敵人。
- 三張卡可作前景 UI，但背景必須持續顯示祭壇與玩家。
- 選定後對應徽記落入玩家胸口，祭壇熄滅，東門開啟。

### 5.5 第二戰鬥房
- 尺寸約 22×15 個地磚，是切片最大的房間。
- 遭遇內容保持焰奴 ×2＋影刺客 ×1。
- 入口位於西側，出口位於東北側。
- 中央有一個低矮、不可碰撞的破碎王徽馬賽克，作為構圖中心。
- 四個火盆分佈於四角，其中一個熄滅，避免完美對稱。
- 影刺客從斷柱陰影顯形，兩隻焰奴從不同火盆旁起身。
- 敵人生成位置仍以 core 為準；場景裝飾不得假裝成不同判定位置。
- 選定印記的第一次可用時機必須在敵人進攻前清楚展示。
- 清場後東北出口門由暗紅轉為金白，形成明確終點。

### 5.6 出口長廊
- 尺寸約 10×7 個地磚，只需 3–5 秒抵達終點。
- 長廊末端向上延伸，白金晨光穿過塵埃落下。
- 牆面由焦黑石逐漸過渡到帶王城雕紋的灰石。
- 勝利不是敵人倒下立即切畫面；先保留控制，讓玩家走出地城。
- 若現有 `victory` phase 在清場當 tick 即成立，表現層仍播放 2–3 秒出口收尾。
- 出口互動不新增平衡獎勵，只完成本切片敘事閉環。

## 6. 房間畫面構成
### 6.1 視角與層次
- 採俯視偏斜視角，可同時看見地面與牆體正面。
- 地磚是角色腳底的空間基準，不以純黑當地面。
- 後牆高度約 1.5–2 個地磚，前牆只顯示矮牆頂緣，避免遮住玩家。
- 角色腳底、柱腳與火盆必須有方向一致的接觸陰影。
- 高物件遮住角色時，以半透明或輪廓顯示維持操作可讀性。
- 戰鬥可玩區與牆面以材質、亮度和邊緣收口區分，不畫發光競技場圈。

### 6.2 構圖優先順序
- 第一優先：玩家、敵人與攻擊預兆。
- 第二優先：門、祭壇與行進方向。
- 第三優先：可辨識的牆、地磚、柱、火盆與裂縫。
- 第四優先：灰塵、火星、煙霧與裝飾碎片。
- 環境粒子不得覆蓋敵人輪廓或與攻擊預兆使用相同飽和色。
- 房間邊緣比中央低一級亮度，視線自然落在可玩區。

## 7. 原創像素美術基準
- 建議角色基準高度 28–40 像素，最終顯示可做整數倍率放大。
- 實際基準解析度由 Visual Director 依 viewport 驗證後決定，不鎖死 160×90。
- 所有 sprite 在原始像素網格上繪製，縮放時避免雙線性模糊。
- 動畫可採逐幀像素精靈，不要求每個物件同一尺寸畫布。
- 輪廓不可只靠色相區分；灰階下仍須辨認玩家與兩種敵人。
- 不直接臨摹任何既有作品的勇者頭盔、披風、怪物或 UI 外框。

## 8. 玩家造型
### 8.1 輪廓
- 身形偏小而直立，頭身比約 1:2.5。
- 戴有缺角的灰銀頭盔，露出一小撮暖棕髮，不使用知名角色的尖帽或固定配色。
- 左肩覆暖白短披風，右手持焦黑短劍，形成不對稱輪廓。
- 披風下緣有餘燼紅色破損織紋，呼應印記主題。
- 面向四方向時，劍與披風的位置必須交換或偏移，不能只鏡像整張圖。

### 8.2 色彩
- 主體：灰銀、暖白、深棕。
- 強調：低面積橘紅，只出現在劍刃反光與披風織紋。
- 受傷時使用短促白閃加暗紅邊緣，不把整個角色長時間染紅。
- 無敵幀以淡金輪廓間歇閃動，不使用透明到看不見的做法。

## 9. 焰奴造型
### 9.1 輪廓
- 比玩家寬約 25%，駝背、雙臂下垂，步態沉重。
- 頭部像裂開的煤殼，裂縫內有呼吸般明滅的暗橘火光。
- 左臂套著不完整石枷，右臂握短柄炭錘。
- 肩膀高低不一，避免成為普通紅色人形兵。
- 接近時身體前傾；預兆時高舉炭錘，輪廓高度明顯增加。

### 9.2 色彩與辨識
- 主體使用煤黑、焦褐與低飽和磚紅。
- 火光集中在頭部裂縫與錘面，不讓全身發紅。
- 攻擊預兆以頭部裂光收縮加錘面升溫表達。
- 即使關閉敵人名稱與血條，仍應由寬身、駝背、炭錘辨認。

## 10. 影刺客造型
### 10.1 輪廓
- 比玩家高而窄，腰部前傾，四肢呈尖銳折線。
- 臉部被裂邊面罩遮住，只留一條冷青目光。
- 雙手各持短刃，一前一後形成快速攻擊方向。
- 背後有兩條短碎布，不做長披風，避免與玩家混淆。
- 移動時採低姿態滑步；預兆時壓得更低，再沿殘影線突進。

### 10.2 色彩與辨識
- 主體使用深紫灰、藍黑與少量冷青。
- 不以純黑填滿，確保在暗牆與陰影前仍有外輪廓。
- 殘影是稀疏的紫灰分身，不是連續霧帶。
- 即使關閉敵人名稱與血條，仍應由窄身、雙刃、低姿態辨認。

## 11. 環境元件
### 11.1 地磚
- 主地磚是灰褐石板，每塊有 2–3 種邊角破損變體。
- 戰鬥中央使用較平整版本，邊緣增加碎屑與灰塵。
- 地磚接縫低對比，不得形成會被誤認為移動網格的粗線。
- 少量王城金屬嵌線可指向門與祭壇，但不發出持續霓虹光。

### 11.2 牆與門
- 牆由深灰石塊、焦痕與局部坍塌構成。
- 後牆可掛破損旗布，圖案使用本作原創三瓣餘燼徽記。
- 戰鬥門是厚木與鐵條結構，關閉時有實體重量感。
- 封印只覆蓋門縫與門楣，不用巨大紅色透明牆堵住畫面。
- 開門需有抬升、落灰與火光變化，至少 8–12 幀可感知過程。

### 11.3 火盆
- 火盆由黑鐵三腳架與橘黃火焰組成。
- 火焰至少有 4 幀循環，亮度不可每幀大幅跳動造成閃爍疲勞。
- 火盆附近地磚有有限暖光，不照亮整個房間。
- 熄滅火盆保留灰燼與細煙，作為戰後衰敗線索。

### 11.4 柱與裂縫
- 完整柱只放房間邊緣；中央使用低矮斷柱或純地面柱基。
- 柱頂與柱身使用不同明度，讓玩家看懂高度。
- 地裂縫不可與影刺客殘影同色，也不可畫成可跌落深坑。
- 裂縫邊緣偶有暗紅餘火，但不造成傷害、不暗示隱藏碰撞。

### 11.5 印記祭壇
- 祭壇是三層不規則石台，中心嵌一枚熄滅的三瓣餘燼徽記。
- 三個選項出現時，三瓣分別燃成橘紅、紫青、金白。
- 祭壇周圍石柱只到玩家腰高，不遮住卡片與角色。
- 選定後其他兩瓣化為灰燼，選中的一瓣飛向玩家。

## 12. 動畫狀態與幀率
### 12.1 共通原則
- 邏輯仍以 100Hz 推進，動畫取樣與畫面渲染不得反推 core tick。
- 一般角色動畫建議 8–12 fps；快速招式可到 12–16 fps。
- 火焰與輕粒子可用 8–12 fps，介面 tween 可按顯示幀率平滑更新。
- 關鍵命中幀必須與 `GameEvent` 同步，不可只按動畫預估時間自行判定。
- 動畫插值不能讓腳底離開 core 實際位置太遠。

### 12.2 玩家動畫表
| 狀態 | 建議幀數 | 建議播放率 | 視覺要求 |
|---|---:|---:|---|
| 待機 | 4 | 6 fps | 呼吸、披風輕擺、劍尖微沉 |
| 行走 | 6 | 10 fps | 四方向步態、腳步接地清楚 |
| 攻擊一 | 5 | 14 fps | 橫斬、前腳踏出、命中幀明確 |
| 攻擊二 | 5 | 14 fps | 反向回斬，與第一段輪廓不同 |
| 攻擊三 | 6 | 14 fps | 突刺或終結斬，位移方向清楚 |
| 閃避 | 6 | 16 fps | 壓身、位移、落地，不做旋轉球 |
| Q | 6–8 | 14 fps | 依印記版型表現施放前後姿勢 |
| E | 6–10 | 14 fps | 依印記版型表現蓄力與釋放 |
| 受傷 | 3 | 12 fps | 反向後仰，不覆蓋太久控制讀性 |
| 死亡 | 8–10 | 10 fps | 跪倒、劍落地、餘火熄滅 |
| 勝利 | 6 | 8 fps | 收劍與短暫喘息，不做誇張慶祝 |

### 12.3 焰奴動畫表
| 狀態 | 建議幀數 | 建議播放率 | 視覺要求 |
|---|---:|---:|---|
| 待機 | 4 | 6 fps | 裂光呼吸、駝背晃動 |
| 接近 | 6 | 8 fps | 沉重拖步、炭錘低垂 |
| 預兆 | 6 | 10 fps | 高舉炭錘、裂光由散到聚 |
| 攻擊 | 5 | 14 fps | 錘擊落地，判定幀與事件同步 |
| 受傷 | 3 | 12 fps | 煤屑飛散、身體短促後縮 |
| 死亡 | 8 | 10 fps | 跪倒裂開、內火熄滅成灰 |

### 12.4 影刺客動畫表
| 狀態 | 建議幀數 | 建議播放率 | 視覺要求 |
|---|---:|---:|---|
| 待機 | 4 | 8 fps | 低姿態、雙刃微動 |
| 接近 | 6 | 12 fps | 側滑繞行、步幅輕快 |
| 預兆 | 5 | 14 fps | 下蹲、殘影線收束 |
| 攻擊 | 6 | 16 fps | 突進刺擊，起點終點可追蹤 |
| 受傷 | 3 | 14 fps | 面罩亮線斷續、身體偏折 |
| 死亡 | 7 | 12 fps | 失衡翻倒、殘影向內消散 |

## 13. 戰鬥視覺回饋
### 13.1 普攻與連段
- 第一段斬弧短而寬，第二段方向相反，第三段更集中且更亮。
- 斬弧存在時間控制在 80–140ms，不形成常駐光扇。
- 命中時敵人閃白 1 幀、噴出 3–6 顆方向性像素火花。
- `comboHit` 觸發 35–55ms hit-stop；第三段可略長，但不得改 core 時間。
- `comboWhiff` 不播放命中火花、傷害數字或重型音效。
- 傷害數字不是主要回饋，可小型顯示並在 0.5 秒內淡出。

### 13.2 玩家命中、受傷與死亡
- 成功命中要同時具備形變、亮閃、粒子和音效中的至少三項。
- `playerHit` 時玩家向傷害來源反向抖動 2–3 像素，鏡頭只做極輕震動。
- 生命條損失分成即時紅條與延遲暗條，讓傷害量可讀。
- 受傷紅暈只在畫面邊緣出現，中心戰鬥區保持清楚。
- `defeat` 後先播玩家死亡動畫，再顯示敗北面板。
- 敵人死亡必須留有 0.3–0.6 秒倒下或崩解過程，不可瞬間刪除。

### 13.3 閃避與格擋
- `dodgeStart` 產生一段短披風殘像與腳底塵線。
- 一般閃避殘像使用暖灰；精準閃避使用一圈冷白收束線。
- 無敵幀不得以整個角色消失表示。
- 彎曲閃避的軌跡用三個離散殘像顯示弧度，不畫工程用貝茲線。
- `playerBlocked` 產生金白六角碎光、清脆金屬聲與短促文字「格擋」。
- 格擋回饋不能與玩家受傷共用紅色閃光。

### 13.4 Q／E 基礎版
- 基礎 Q 突進斬：前方出現窄而明亮的劍路，角色姿勢先壓低再刺出。
- 基礎 E 破隙衝擊：以玩家為起點向前爆出短距離碎石與半圓衝擊紋。
- 冷卻中按下按鍵時，只讓 HUD 槽位輕晃，不播放施法起手。
- `eFailed` 必須給低音量失敗聲與槽位暗閃，不假裝技能已施放。

## 14. 三枚印記視覺語言
### 14.1 餘燼核心
- 色彩：橘紅核心、暗褐外殼、武裝完成時金黃裂紋。
- Q 放置時，玩家把劍尖點地，火種沿短弧落到 core 指定位置。
- 未武裝核心低亮度脈動，不得看起來已可引爆。
- `coreArmed` 時外殼裂開一圈，播放清楚的升調聲。
- 彎曲閃避以離散火星向核心偏折，顯示「路徑被吸引」。
- `coreDetonated` 產生向外翻起的環形火浪與中心瞬間真空，不做滿屏爆炸。
- 攻擊加成期間，玩家劍刃保留一條穩定橘紅餘光。

### 14.2 精準殘影
- 色彩：深紫、冷青、低透明銀灰。
- 精準閃避成功時，在起點留下與玩家同姿勢的像素殘像。
- 殘像輪廓清楚但內部簡化，避免被誤認為第二名玩家。
- 殘像接近消失時由腳向頭碎裂，不以整張圖均勻淡出。
- E 瞬移時，舊位置與殘像位置各出現一次交叉刃光。
- 瞬移路徑只閃現 2–3 個離散節點，不畫持續雷射線。
- HUD 的 E 槽位以殘像小刻痕表示可用充能。

### 14.3 蓄能反震
- 色彩：金白、琥珀、低飽和鐵灰。
- 每次成功閃避增加一片環繞玩家的盾瓣，最多三片。
- 盾瓣保持在角色近身範圍，不遮住敵方預兆。
- 格擋尾段以盾瓣短暫合攏表示，不畫常駐大盾。
- E 釋放時盾瓣向外翻成三段衝擊環，層數越高完整度越高。
- 施放後盾瓣清空的消散方向必須向外，清楚表達資源已花費。
- 三層滿蓄能時 HUD 與角色只各提示一次，不持續閃爍。

## 15. 敵人預兆
- 焰奴進入 `telegraph`：頭部裂光由外圈向錘面收束，地面出現短而寬的暗紅落點。
- 焰奴預兆 500ms 的最後 100ms，錘面轉亮但落點形狀不改變。
- 影刺客進入 `telegraph`：身體下蹲，身後生成一條冷紫殘影預告突進方向。
- 影刺客預兆 350ms 的最後 80ms，殘影由三段收束成一段。
- 兩種預兆不可只靠紅色深淺區分；形狀、姿勢與動態都不同。
- 預兆位於世界空間，鏡頭移動時與敵人位置一致。
- 環境火光、印記特效與傷害數字不得蓋住預兆核心輪廓。

## 16. HUD
### 16.1 常駐資訊
- 左上：玩家頭像、目前生命／最大生命、長條生命槽。
- 左下或下中：攻擊連段提示、閃避、Q、E 四個行動槽。
- 每個槽位顯示目前實際綁定鍵位，不寫死 Space、Q 或 E。
- 閃避、Q、E 使用遮罩或環形進度顯示冷卻，不只顯示秒數。
- 右上：目前房間與目標，例如「熄火前室｜擊敗焰奴」。
- 已選印記出現在生命條下方，使用單一清楚徽記，不開永久側欄。
- 敵人頭頂生命條只在受傷後或被鎖定威脅時顯示，避免滿場 UI。

### 16.2 戰鬥狀態
- 進入戰鬥時目標文字由「探索」切成「擊敗敵人 0/1」或「0/3」。
- 清場時顯示 0.8 秒「道路已開啟」，同時讓門本身發生變化。
- HUD 不用大面積黑色矩形遮住地城。
- 所有繁體中文至少在 1280×720 下可讀，不用低解析像素字硬縮。
- UI 可用像素邊框，但文字渲染優先確保清晰與字形完整。

## 17. 印記卡與祭壇選擇
- 三張卡橫向排列於畫面中央偏下，背景保留可見但降低明度。
- 每張卡包含：印記名、原創徽記、改變的按鍵、前後動作示意、兩行內摘要。
- 餘燼核心卡必須畫出「Q 放核心 → 閃避掃過 → 爆炸」三步圖。
- 精準殘影卡必須畫出「精準閃避 → 留影 → E 瞬移」三步圖。
- 蓄能反震卡必須畫出「閃避蓄能 → 盾瓣累積 → E 反震」三步圖。
- 卡片強調色分別為橘紅、紫青、金白，但外框結構一致。
- 鍵盤、滑鼠與手把選擇皆需有清楚焦點框。
- 確認選擇前可切換焦點；確認後 0.5 秒內鎖定，避免重複輸入。
- 不顯示未納入切片的後續印記、稀有度、價格或技能樹。

## 18. 勝利、敗北與重開
### 18.1 勝利
- 第二戰鬥房清場後先播放敵人死亡與開門演出。
- 玩家保留控制並走過出口長廊。
- 到達光門後畫面升亮，顯示「餘火未熄」。
- 勝利面板列出所選印記與本次完成時間即可。
- 提供「再試一種印記」主按鈕與「返回平台」次按鈕。
- 不顯示不存在的金幣、經驗、解鎖或排行榜。

### 18.2 敗北
- 玩家生命歸零時停止接受戰鬥輸入，但讓世界動畫繼續短暫收尾。
- 鏡頭輕微拉近玩家，火盆降低亮度，0.8–1.2 秒後顯示敗北面板。
- 面板標題「餘火熄滅」，列出到達房間與已選印記。
- 主按鈕為「重新挑戰」，按下後回到入口前室或遭遇一開頭。
- 不用責備式文案，不顯示「太弱」「菜鳥」等文字。

### 18.3 快速重開
- 切片專用快速重開可保留，HUD 以小型提示呈現目前綁定鍵位。
- 戰鬥中觸發時先開 1 次確認；勝敗面板觸發時可直接重開。
- 重開清空已選印記、殘影、核心、蓄能、敵人與冷卻，遵從 core 既有行為。
- 重開不重新載入頁面、不重抓資產、不留下上一局粒子或音效。

## 19. 鏡頭規格
- 基準 viewport 以 1280×720 驗收，需同時適應常見 16:9 桌面尺寸。
- 鏡頭採單房間跟隨，不要求整座地城同時入鏡。
- 玩家位於畫面中心周圍 12% 寬、10% 高的 dead zone 內時鏡頭不移動。
- 超出 dead zone 後鏡頭以 120–180ms 緩動追上，不用彈簧過衝。
- 進門時可短暫向下一房間偏移，先展示敵人和出口，再回到玩家。
- 戰鬥中鏡頭不得自動追敵或突然縮放。
- 命中震動 1–2 像素；玩家重傷或核心爆炸最多 3–4 像素。
- 不使用旋轉鏡頭、色差、動態模糊或長時間螢幕搖晃。
- 畫面縮放必須保持像素清晰；若 viewport 無法整數放大，以 letterbox 或裁切策略處理。

## 20. 座標映射
- core `Vector2` 是唯一戰鬥世界座標，不直接等於像素或地磚索引。
- 表現層定義一致的 `worldUnitsPerTile`，建議從 1 單位＝1 地磚開始驗證。
- 螢幕映射順序：core 世界座標 → 房間局部座標 → 鏡頭座標 → 畫面像素。
- 角色腳底中心對齊 core position；精靈頭部與武器可超出碰撞中心。
- 敵人預兆、餘燼核心、殘影與傷害特效都使用相同世界轉螢幕函式。
- HUD 使用螢幕座標，不跟著鏡頭位移。
- 房間裝飾可使用 tile 座標，但不得改寫或吸附 core position。
- 插值只發生在上一個與目前 core position 之間，不預測下一 tick。
- 房間門與展示動線屬表現層狀態，不可偽造敵人已死亡或印記已選取。
- 若 core 遭遇仍以玩家原點為中心生成，房間 anchor 應把整組座標平移到房內，不改數值本身。

## 21. 表現狀態與 core 對照
| core 狀態／事件 | 地城表現 |
|---|---|
| `encounter1` | 入口前室與第一戰鬥房；焰奴起身、門封閉 |
| `encounterCleared: z1-e1` | 第一房門封印碎裂，鏡頭指向祭壇 |
| `draft` | 印記祭壇點亮，三張卡開啟 |
| `markSelected` | 徽記進入玩家，祭壇東門開啟 |
| `encounter2` | 第二房封閉，焰奴×2與影刺客×1登場 |
| `encounterCleared: z1-e2` | 敵人收尾、出口門亮起 |
| `victory` | 出口長廊與勝利收尾，不立即黑屏 |
| `defeat` | 玩家死亡動畫與敗北面板 |
| `restart` | 清空表現暫存並回到切片起點 |
